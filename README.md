# FreeFlarum Extensions

Vibecoded forks of Flarum v1 extensions, just to provide compatibility with Flarum v2.

## Motivation

A lot of Flarum v1 extensions didn't make it to Flarum v2, and some were abandoned entirely.
This makes it difficult for FreeFlarum users, as lots of them relied on extensions that are no longer maintained, and
would likely never see a Flarum v2 release. Therefore, I have decided to go ahead and fork the extensions for a minimal v2
compatibility.

## Disclaimer

These extensions were all coded by AI (Claude Opus 5.5 xhigh effort) under MINIMAL SUPERVISION, from the original extensions
(according to their license).

While most of them are being used on FreeFlarum and have been tested, they are not guaranteed to work perfectly.
There will be NO new features and MINIMAL bug fixes, as time allows.
